# WeDraft

WeDraft 是一个只在个人 Mac 上运行的微信公众号快速排版工具。它不连接微信接口，不需要公网 IP、AppID、AppSecret、服务地址或设备令牌。

当前版本：`1.1.2`

更新日期：`2026.08.26`

## 使用方式

1. 将完整文章粘贴到唯一输入框，第一行固定作为标题；
2. 第二行开始的内容会立即识别段落和结构并套用默认主题；
3. 在同一页面切换排版模板和“网页版 / iPhone / Android”预览；预览区始终显示，不需要单独打开；
4. 点击“复制排版”写入剪贴板；
5. 点击同尺寸的“打开公众号后台”，新建图文并粘贴正文。

编辑区工具栏提供“复制Markdown规则”按钮，可一键复制当前最新版写作提示词。将它发给 ChatGPT 等 AI 后，AI 会按照 WeDraft 支持的标题层级、粗体金句、引用、列表、代码、说明文字、分隔线和文末参考来源规则输出文章。

编辑框顶部提供分组式 Markdown 快捷工具栏。所有格式按钮单击一次立即生效；一级/二级标题、引用、列表、说明等行级格式会直接作用于光标所在行，再次点击即可取消；粗体和行内代码支持包裹与解除；代码块和分隔线也支持反向操作。工具栏最右侧提供多步“撤回 / 重做”，也支持 ⌘Z 和 ⌘⇧Z。工具栏中的“添加正文图片”是唯一图片入口，选择本机图片后可填写来源或选择无来源，图片会缓存到 WeDraft、实时显示并随富文本一起复制。

JPG、PNG 和 WEBP 在插入时会检测尺寸与体积，超过 2400px 的长边会等比缩小，较大图片会在本机重新编码并显示优化结果。GIF 为保留动画会原样缓存，体积过大时明确提醒。

应用只排版并复制文章正文，不会自动添加顶部品牌动图、固定感谢语、封面来源或合作联系信息；这些内容可继续由公众号后台模板统一添加。

左侧 Markdown 编辑区与右侧预览区使用内容锚点双向同步：标题、段落、图片、引用、列表、代码和参考来源都保留对应关系，滚动时按照“同一内容块 + 块内高度进度”定位，不受左右高度差异影响。悬停右侧排版区块时，左侧对应 Markdown 行会整块高亮并在需要时自动定位；左侧移动光标或编辑内容时，右侧对应排版区块也会实时高亮。

右侧微信预览支持安全的文字微调：可直接点击标题、正文、章节标题、引用、列表、表格单元格和参考来源，修改错字、替换短句或补充一句话；离开编辑位置后会精确写回对应 Markdown 内容块，并进入同一套撤回/重做历史。图片、代码和分隔线继续在左侧编辑，避免破坏结构。左侧编辑框右侧另有文章缩略导航条，以层级颜色标记一、二级章节和正文块，点击即可定位到对应 Markdown 行，导航框同步显示当前可视范围。

每次启动或新建文章时，编辑区会先展示一篇完整组件样稿，右侧同步显示实际排版效果。样稿包含一张内置图片：图片自动适配正文宽度、左右各留 8px，右下方以灰色小字标明图片来源。鼠标经过不会改变样稿；只有点击编辑区或通过键盘让输入框获得焦点、出现输入光标后，样稿才会清空。样稿不会被保存、复制或写入文章历史。

复制时只复制第二行开始的正文，不复制标题；同时写入 HTML 富文本和纯文本两种剪贴板格式。公众号编辑器会读取 HTML 并保留字号、行距、颜色、粗体、章节、引用、列表和图片；普通文本框仍能读取纯文本。

点击“复制排版”时会先检查图片、表格、章节编号、章节分隔线和参考来源位置。每项问题都显示 Markdown 行号，点击即可让编辑区与预览区同步定位。必须修正的问题会阻止复制，修正后重新点击即可通过；普通兼容性提醒可确认后继续复制。

## 默认主题：小哈公社

默认主题按照以下四篇现有文章的共同样式实测还原：

- [蒸馏就是 AI 时代的“合法”抢劫](https://mp.weixin.qq.com/s/bIcZCrDXhfPW4crIS86RjQ)
- [存储涨疯了，涨的到底是什么？](https://mp.weixin.qq.com/s/l8V4FQOykn6cWWDnxf-iTg)
- [AI 最大的生意，藏在软件公司最嫌弃的地方](https://mp.weixin.qq.com/s/EZn114w8hgonqDde-EPWQQ)
- [导演梦，不再需要剧组](https://mp.weixin.qq.com/s/nabh03iaQrfV3eWE3jYshg)

主要规则：

- 正文 15px、1.75 倍行距、0.5px 字距、两端对齐；
- 正文左右各 8px、段后 24px；
- 二级标题编号为 25px 斜体珊瑚红，标题文字为 15px 粗体橙色；
- 粗体保留黑色强调，图片自适应正文宽度；
- 引用、列表、三级标题和分隔线自动映射到同一视觉体系。
- Markdown 的 `>` 渲染为引用卡片，并在内容同一行开头显示中文左双引号 `“`；金句使用 `> **金句内容**`。
- Markdown 围栏代码块保留换行和缩进，并使用适合公众号的等宽字体样式。
- 文末使用“参考来源”标题并紧跟编号列表时，会自动生成带 `01–05` 编号的参考来源组件。

模板切换位于编辑页面的预览区顶部，不需要进入设置页。当前提供：

- 小哈公社：按照参考文章还原，默认使用；
- 小哈公社New：默认模板，面向公众号长文的精简阅读主题，强化章节层级、段落留白、列表、引用、图片说明与来源说明。完整规则见 [`docs/next-edition-guidelines.md`](docs/next-edition-guidelines.md)。

预览区提供微信公众号网页版、iPhone 17 Pro Max 和 Samsung Galaxy S26 Ultra 三种视口。两种手机预览分别按 1320×2868 和 1440×3120 的屏幕比例绘制，三种模式的正文区域都可独立滚动。

## 本地数据

- 只有执行“复制排版”后，文章才会进入本地历史；
- “未命名文章”或正文为 0 字的空文章不会保存或显示在最近文章中；
- 最近文章支持重新打开、单篇删除和清空全部；两种删除都会先显示应用内确认弹窗，确认完成后列表立即刷新；
- 正文图片缓存在同一 App 数据目录；
- 本地图片复制时会嵌入富文本剪贴板；
- 不保存或请求任何微信凭证；
- 不启动服务器，也不向 WeDraft 自有服务发送内容。

## 开发

要求：

- Apple Silicon Mac；
- Node.js 22+；
- pnpm 11；
- Rust stable；
- Xcode Command Line Tools。

```bash
pnpm install
./scripts/setup-git
pnpm dev
./scripts/verify
pnpm build:mac
```

`pnpm build:mac` 固定构建 `aarch64-apple-darwin`，不构建 Intel 版本。

## 项目与版本管理

本地 Git 负责开发、审阅、合并和版本管理；[pafa/WeDraft](https://github.com/pafa/WeDraft)（私有）只保存源码备份。所有更新在任务分支完成，经本地检查与维护者批准后合入本地 `main`，再推送备份。

- [本地 Git、备份与发布规则](docs/git-workflow.md)
- [版本记录](CHANGELOG.md)
- [软件验收清单](docs/acceptance-tests.md)

不要求 GitHub PR、强制分支保护或线上 CI，也不需要升级 Pro 或增加 workflow 权限。每次完成工作后执行 `./scripts/backup`，提交过的当前分支会上传并核对远端 SHA；未提交的改动、文章数据和安装包不在源码备份范围内。

## 快捷键

- `⌘ ⇧ C`：复制当前排版；
- `⌘ N`：新建文章；
