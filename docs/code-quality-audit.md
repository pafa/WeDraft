# 代码质量审核与修复

审核日期：2026-09-19。基线：`9d3dcd8`（PR #3 合并后的 main）。本记录针对修复候选，不代表已经发布、替换本机 App 或验证所有真实微信环境。

## 范围与方法

按模块检查 Web、Mac 前端、共享编辑器、解析/模型/渲染/校验、Core、CLI、MCP、安装器、Rust 存储/导出和构建脚本。结合源码引用检查、边界输入复现、回归测试、浏览器交互、样式前后比较和原生构建。只删除可证明未使用的实现；保留平台适配层和本地数据边界。

## 冗余清理与持续检查

- 删除 8 项没有源码使用点的直接依赖：Mac 的 `@hookform/resolvers`、`react-hook-form`、`zod`、`zustand`；Web 的 `@wedraft/article-model`、`@wedraft/article-parser`、`@wedraft/shared-types`、`fake-indexeddb`。仍被共享包使用的 Zod/Zustand 保留在真正使用它们的包中。
- Mac 新增 `@wedraft/core` workspace 依赖来复用源语法校验，不另造一套重复规则。pnpm 锁文件同步，没有升级第三方包版本。Rust 显式复用锁文件中已有的 `icu_normalizer 2.2.0` 做文件名规范化，没有引入新的 crate 版本。
- 删除 76 行旧草稿列表、旧搜索框、旧 AI 介绍区等无使用点的 CSS；24 个视图组合比较保持相同视觉结果。
- 删除导入入口重复的 `renderArticle` 调用，保留替换文章前的唯一校验入口。
- TypeScript 基础配置启用 `noUnusedLocals` 和 `noUnusedParameters`，之后的标准验证会阻止新的未使用局部变量、导入和参数进入代码。
- 未把共享 UI 中仍供 Mac 使用的样式或平台适配器误删；不以减少行数为目标进行大规模重写。

## 保留边界

- ZIP 校验不依赖解压库的私有字段；不承诺拒绝所有短尾随字节。解压输出和连续无输出输入都有上限，但不是进程峰值内存的严格上限。
- 本次是基于源码、测试和本机浏览器的质量审核，不是形式化证明或完整安全渗透测试。
- 未验证真实微信后台、真实系统输入法组合、Safari/Firefox 全流程、Linux 冷安装或所有 AI 宿主；模拟 composition 事件通过不等于所有输入法人工验收。
- 原生构建仍采用现有 ad-hoc 签名，没有公证、安装、发布或版本升级。
- Vite 开发环境仍有现有依赖的 browser-externalized 警告；生产构建体积提示不在本次纠错范围。
- Web 的非 Mac 平台 Ctrl 组合快捷键属于后续跨平台完善项；当前操作按钮与可访问名称保留。
- 未删除用户缓存、历史数据库、旧发布包或其他工作树，不变更仓库公开状态与生产部署。
