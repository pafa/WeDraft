# 验收测试

## 自动化

```bash
pnpm verify
cd apps/desktop/src-tauri && cargo test
```

应满足：

- TypeScript 类型检查通过；
- 文章解析、HTML 清理、主题渲染、校验、状态管理测试通过；
- 本地图片可嵌入富文本剪贴板；
- Rust 存储、图片缓存和剪贴板代码构建通过；
- Web 前端和 Apple Silicon Tauri 构建通过。

## 实时排版与复制

输入：

```markdown
# 示例文章

第一段正文。

## 1. 第一章节

这里有 **重点内容**。

> 这里是引用。
```

验收：

- 输入区没有独立标题框，第一行显示为预览标题且不进入正文；
- 复制出的 HTML 和纯文本都不包含第一行标题；
- 预览正文为 15px、1.75 倍行距；
- 段落左右 8px、段后 24px；
- “1.” 为珊瑚红 25px 斜体；
- “第一章节”为橙色 15px 粗体；
- 粗体与引用样式正确；
- 点击“复制排版”后才写入剪贴板、保存文章历史并显示复制成功。
- 页面右下角不存在“一键排版”按钮；
- 复制成功后，“打开公众号后台”和“复制排版”两个按钮尺寸完全一致。

## 启动组件样稿

1. 重新打开 App，或点击“新建文章”；
2. 不移动到编辑区，观察左右两栏；
3. 将鼠标移入编辑区，或点击编辑区。

验收：

- 左侧初始显示完整 Markdown 样稿，右侧立即显示真实排版；
- 样稿包含文章标题、一级章节、二级章节、正文、粗体、金句引用、列表、代码块、分隔线和参考说明；
- 样稿最底部显示带 `01–05` 编号的独立“参考来源”组件；
- 样稿状态下“复制排版”不可用；
- 鼠标经过编辑区时样稿保持不变；点击或键盘聚焦编辑区后样稿立即清空，预览恢复空状态；
- 样稿不会保存、复制或进入文章历史。

## 单页模板切换

1. 在编辑器粘贴包含二级标题、引用和多段正文的文章；
2. 依次点击“小哈公社”“小哈公社New”；
3. 不离开编辑页面依次切换网页版、iPhone 和 Android 预览。

验收：

- 页面不存在单独的排版设置栏或偏好入口；
- 两个模板都能立即生效；
- “小哈公社New”默认选中，并能区分章节编号、三级标题、重点、引用、列表、图片说明和“参考/来源/注”段落；
- 切换模板不会修改原文；
- 重启后保留最后选择的模板。

## 最近文章管理

1. 执行“复制排版”，进入“最近文章”；
2. 点击文章主体；
3. 返回最近文章，点击一篇文章右侧删除按钮并确认；
4. 点击“清空全部”并确认。

验收：

- 点击文章主体会返回排版页面并载入标题、正文和实时预览；
- 每篇文章右侧都有独立删除按钮，点击不会误触打开文章；
- 清空全部显示待删除文章数量并要求二次确认；
- 删除后列表和文章数量立即刷新；
- 删除操作只影响本机文章历史。

## 三端预览滚动

1. 粘贴一篇足够长的文章；
2. 滚动左侧 Markdown 编辑区；
3. 再滚动右侧网页版、iPhone 或 Android 预览；
4. 在文章中间位置修改一段文字。

验收：

- 左侧滚动时右侧按相同阅读进度同步；
- 右侧滚动时左侧按相同阅读进度同步；
- 修改内容后右侧立即更新，并保持修改前的阅读进度；
- 切换预览设备后继续保持当前阅读进度。

粘贴至少 30 段的长文章，依次切换三种预览并在正文内滚动到末尾。

验收：

- 三个设备按钮分别显示网页版、iPhone 和 Android；
- 设备标识分别显示微信公众号网页版、iPhone 17 Pro Max 和 Samsung Galaxy S26 Ultra；
- 网页版显示浏览器栏，两种手机显示各自的状态栏和设备外框；
- 状态栏、浏览器栏和公众号导航保持固定；
- 只有正文内容滚动；
- 可以到达最后一段，外层页面不需要跟随滚动。

## 公众号后台粘贴

1. 在 WeDraft 复制上述文章；
2. 打开微信公众号后台并新建图文；
3. 将焦点放入正文编辑区并粘贴；
4. 分别检查正文、章节、粗体、引用、列表和图片；

验收：

- 正文结构和内联样式保留；
- 不出现 Markdown 标记；
- 不出现 WeDraft 内部图片标记；
- 本地图片随富文本复制；
- 普通文本框粘贴时得到可读纯文本。

## 本地与离线

1. 断开网络；
2. 新建并编辑文章；
3. 点击“复制排版”；
4. 重启 App 并从“最近文章”打开；
5. 再次执行“复制排版”。

验收：

- 编辑、预览、保存、本地图片和复制均不依赖网络；
- 全流程不要求 AppID、AppSecret、服务地址、Token 或公网 IP；
- 应用内不存在连接测试、上传、草稿创建和发布历史入口。
