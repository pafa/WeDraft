# 网页版使用指南（0.1.0 候选）

这是可独立运行的浏览器编辑器，使用与 CLI、MCP 相同的排版核心。Mac 已发布基线仍为 1.1.2；两者的草稿存储彼此独立。

## 启动与使用

在已安装依赖的源码目录执行 `pnpm dev:web`，打开终端显示的地址，默认是 `http://127.0.0.1:1432/`。不需要 Rust、微信凭据或模型 API Key。正式域名已确定为 `https://wedraft.xiaoha.org`，当前尚未部署。

1. 首次打开直接展示含图片的完整排版示例，原稿以灰色显示。点击编辑区即清空示例并出现输入光标，可直接输入或粘贴，无需先点新建。示例不会被复制或导出。第一行是标题，其余是正文。
2. 用工具栏添加章节、图片、来源和列表。可以直接在预览中微调文字，修改会写回原稿，并支持撤回重做。
3. 预览顶部只显示当前模板，点击“更多模板”进入独立模板库；窄屏使用“编辑原稿 / 阅读预览”切换。手机预览保持固定尺寸，默认整体等比缩放，也可选择 100% 查看。
4. 点击“复制排版”。必须修正的问题会阻止复制，普通提示可检查后继续。标题单独填写，剪贴板只包含正文 HTML 和纯文本。
5. 在公众号后台粘贴，检查图片、链接和手机预览，再自行发布。

自动检查不能证明微信接受全部样式。当前验收覆盖真实 Chrome 的 HTML 剪贴板和浏览器富文本粘贴，尚未完成微信后台与 Safari / Firefox 的实际验收。

## 模板库和设备预览

模板库提供“小哈公社”“小哈公社New”，以及“素笺”“墨刊”“青岚”“蓝图”“朱砂”。桌面每排四款，直接展示七款模板，点击可展开完整预览。底部加号提供 Fork 项目、设计模板和提交 PR 的入口。点击“设为默认并使用”应用到当前文章，并通过 `wedraft_template` Cookie 记住默认模板一年；下次新建和打开新标签时使用该默认值。导入文章包时，保留文章自己的模板。浏览器拒绝 Cookie 时仍可切换当前模板，但会提示无法记住。

模板由共享目录登记，网页、CLI 和 MCP 都读取同一份名单，投稿约定见[模板规范](templates.md)。当前还没有公开投稿入口或动态安装第三方模板。

iPhone 使用 440 × 956、Android 使用 412 × 892 的固定逻辑屏幕，包含时间、网络、电量、灵动岛或摄像孔、微信导航栏和底部安全区。适应窗口时整个机身等比缩放，文章的排版宽度不随面板改变；100% 模式可滚动查看。系统状态为模拟显示，不是读取设备状态，也不能代替真机微信验收。

## AI 接入

顶部“接入 AI”打开两条流程的独立教程：

- **手工整理**：复制产品的 Markdown 格式规则给 AI，将现有文档保真整理为 Markdown，再回网页编辑、选模板、复制到微信；不需要安装 Skill / MCP。
- **自动排版**：一次接入 Skill / MCP 后，将已有 Markdown 交给 AI，用一句指令调用排版。直接打开生成的 `preview.html`，点击“复制正文排版”后粘贴到微信；文章包可用于后续网页编辑，无需每次回网页重新排版。

有浏览器或剪贴板工具的宿主 Agent，可在得到用户指令后继续复制、粘贴到指定草稿。WeDraft 本地 MCP 自身不控制微信或发布文章。安装流程、两套指令和支持范围见[AI 接入指南](ai-integration.md)。本地预览地址只适用于同一台电脑，正式公共地址尚未部署。

## 临时编辑与保留结果

文章与本地图片只在当前页面内存中暂存，切换模板库、AI 页面再返回时保留本次编辑。**刷新、关闭或重新打开页面后，重新显示内置示例，之前的原稿不会恢复。** 网页没有账户或文章管理；需要保留结果时，复制正文或下载 `.wedraft.zip` 文章包。

模板偏好仍由 Cookie 记住，它不包含文章内容。新版不读取、删除或迁移旧候选曾写入的 IndexedDB 草稿；也不读取 Mac 应用数据库。网页与 Mac 承担不同用途，不要求文章历史互通。

## 导入与导出

| 格式 | 用途 |
| --- | --- |
| `.wedraft.zip` | 推荐的可编辑交接格式：完整 Markdown、模板 ID 与版本、作者/摘要/来源链接元数据和本地图片字节。 |
| `.md` / `.markdown` / `.txt` | 文本稿；相对图片路径需要另行提供，不能自动读取用户硬盘。 |
| ArticleInput `.json` | AI / 程序接口格式，字段见 [AI 接入](ai-integration.md)。 |
| 导出的 `.html` | 可独立打开并复制正文排版的预览，嵌入本地图片；远程图片仍依赖原地址。不能反向恢复完整编辑信息，请同时保留文章包。 |

拖入文件或点击“导入”均可。损坏的文章包、未知模板和不兼容版本会报错，当前编辑内容保留。含有不支持语法的草稿仍能导出文章包，以便修复；完成修复前不会导出正式正文 HTML。

文章包保留输入 Markdown，包括原有换行。开始编辑后浏览器会正常化换行符。旧 Mac 的“全部导出 ZIP”是多篇 Markdown 集合，不是本版本的可编辑文章包；请先解压并逐篇导入，缺少的缓存图片需自行补齐。

## 图片与内容边界

- 网页图片保留原始字节，支持 PNG、JPEG、GIF、WEBP；不做 Mac 版的自动压缩。
- 单张最多 10 MiB，网页添加时最多 4000 万像素；一篇最多 64 个图片资产、合计 40 MiB。保留撤回所需的未使用资产，也会纳入文章包。
- 图片文件名、说明和来源写入原稿。填写来源或选择“无来源插入”，程序不会编造出处。
- 正文源文件最多 100 万字符。暂不支持嵌套/任务列表、复杂引用、原始 HTML、删除线、脚注和引用式链接；出现这些语法会明确阻止复制，避免静默丢失内容。
- 远程图片会由浏览器请求来源网站；CLI / MCP 不下载它们。使用外部 AI 时，稿件会按该 AI 产品的数据政策处理。
- 无账号、云同步、遥测或 WeDraft 内容上传服务。生产网站需要 HTTPS 才能可靠使用浏览器剪贴板；localhost 用于本地开发。
