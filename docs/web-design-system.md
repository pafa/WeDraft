# WeDraft 网页界面规范

规范入口为 `apps/web/src/design-system.css`，在布局样式之后加载。所有产品界面使用统一变量；新增页面优先复用现有语义类，不自行添加零散字号。

## 字体层级

| 用途 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面标题：模板库、AI 页面 | 28px，窄屏 24px | 600 | 1.4 |
| 分区与弹窗标题 | 20px | 600 | 1.4 |
| 卡片与步骤标题 | 16px | 600 | 1.4 |
| 正文、导航、标准按钮 | 14px | 400；操作 500 | 正文 1.7；操作 1.4 |
| 辅助说明、状态、标签、紧凑工具 | 12px | 400；操作 500 | 1.6 |

字体使用系统无衬线栈，优先系统字体、苹方和微软雅黑。品牌字标可保留自身设计。页面标题是最高层级，AI 页面不再单独使用营销页超大标题；手机端只收小页面标题，按钮和正文保持可读。

## 按钮

- 主操作：高至少 40px，14px / 500，水平内边距 16px。
- 普通操作：高至少 36px，14px / 500，水平内边距 12px。
- 编辑工具及设备切换：高至少 32px，12px / 500。
- 常规圆角 8px。文案表示动作，同一级操作使用同一字号，不因页面不同而改变。
- 窄屏新建、导入和撤回操作可只显示图标，保留可访问名称；不靠把文字缩到 10px 塞入空间。
- 焦点沿用清晰的 2px 描边，禁用操作显示弱化状态。复制结果和错误提示保留可访问反馈。

## 页面结构

全站顶栏固定，导航、新建和导入在所有页面保持一致。下方内容独立滚动。编辑器用一个紧凑工具行；模板库桌面四列，无搜索和冗长说明；贡献引导只在点击底部加号后出现。

## 适用边界与检查

此规范只控制产品界面，不覆盖微信正文、模板卡片里的文章样张或手机系统栏。Markdown 编辑区与测量层保持相同的 16px 字号和行高，避免文字定位偏移。

检查桌面 1440px、手机 390px 和窄屏 320px：标题层级一致，按钮可见且不截断，无横向溢出；固定顶栏不随正文滚走，新建和导入可从每个页面回到编辑区。
